# Covteam 首页视觉优化规格

日期：2026-10-12。状态：实现与本地验收完成。分支：`codex/taste-redesign`。

## 目标与范围

让访客快速识别西华大学 Covteam、了解研究方向和真实成员、找到招新联系方式。保留 Astro 6、TypeScript、现有成员/奖项/招新数据与 GitHub Pages `/Covteam/` 路径。仅本地修改，不 push、不创建远程 PR、不发布。

## 参考与诊断

- [Taste Skill](https://github.com/Leonxlnx/taste-skill)，采用 [redesign-existing-projects](https://github.com/Leonxlnx/taste-skill/blob/main/skills/redesign-skill/SKILL.md) 的扫描、诊断、局部改造流程：单一强调色、清晰字阶、减少重复卡片、完善焦点与按压状态，保留已有技术栈。
- [网站去 AI 味终极指南](https://echo-tail.github.io/Echo-Tail/2026/02/04/网站去AI味终极指南/)：从品牌和真实内容出发，系统字体、非对称构图、自然文案、响应式和无障碍细节。将方法适配静态站，不机械添加 React、动画库、表单或虚构数据。
- ui-ux-pro-max 查询确认社区主页结构和 Astro 静态组件适合；数据库推荐的红色、玻璃背景不符合本次约束，使用下面的项目配色。
- 当前页面存在多种强调色与渐变、导航和正文色系不一致、方向和招新重复卡片、成员简介依赖悬停、人数附加无依据的 `+`、移动导航占据过多空间。
- `Covteam-hack.jpg` 实际是黑客主题插画，不是团队活动照片。首屏以原有团队 Logo 为视觉核心，不将素材标注为真实合影。

## 设计系统

定位：大学 CTF 战队的技术档案。DESIGN_VARIANCE=6、MOTION_INTENSITY=3、VISUAL_DENSITY=5。

- 深灰绿背景 `#111715`，次级表面 `#19221e`，正文 `#edf1e9`，辅助文字 `#aab7ae`，唯一 UI 强调色 `#b4d982`。原始 Logo 保持原色。
- 正文使用 macOS/Windows 系统中文字体；编号、年份和技术标签使用系统等宽字体，无外部字体请求。标题采用 500–700 字重、负字距和 fluid 字号。
- 内容最大宽度 1200px，8px 间距节奏；桌面非对称首屏和侧栏式章节头，方向为编号条目、奖项为年份档案、成员为紧凑名录、招新为重点联系入口与清单。
- 按钮/头像采用 4px 圆角，内容通过细线和留白分组。无玻璃模糊、无发光、无全站渐变、无强制全屏高度。
- 动效只用于 180–220ms 的交互反馈；支持 reduced-motion，不隐藏待动画揭示的正文。

## 功能与可访问性

1. 保留全部锚点、成员主页、邮件入口与渐进展开；无 JS 时完整展示内容和导航。
2. 移动导航支持展开/收起、Escape 和点击后关闭；按钮具有 aria-expanded/aria-controls，隐藏菜单不进入 Tab 顺序。
3. 导航标记当前章节，并为锚点预留实际导航高度。
4. 成员简介直接可读，静态 article 不产生多余 Tab 停靠；头像保留加载失败回退。
5. 统计使用真实数组长度，明确为已收录奖项。原有 CTF 控制台彩蛋属于团队内容，保留。
6. 有意义图片保留 alt，交互目标至少 44px；焦点可见，正文颜色对比度至少 4.5:1。

## 验收与平台

执行 pnpm check、pnpm build、改动文件格式检查，以及 CLI 驱动的无头浏览器轻量验证（不用 computer use 或内置浏览器）。检查 375/768/1440px 宽度、展开收起、导航、无 JS、减弱动效、静态资源路径和页面横向溢出。macOS 本机验证；Windows 提供相同 fnm/Node 22/pnpm 命令，使用跨平台 CSS/JS，不宣称 Windows 实机验证。
